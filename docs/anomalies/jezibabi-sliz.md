# Ježibabí sliz

Částečně průhledná zelená hrubá síťovina, leží na zemi, stěnách nebo vegetaci. Dotek okamžitě zabíjí. Nebezpečnost střední, je hůř vidět. Bývá v hnízdě [Pavouka](../mutants/pavouk.md). Zdroj: [nebezpečné anomálie](../research/nebezpecne-anomalie.md)
