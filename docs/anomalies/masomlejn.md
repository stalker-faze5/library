# Masomlejn

Neviditelná malá oblast, která rozloží člověka. Rozkládání provází 5 až 10 s pískání nad 87,4 dB. Velmi nebezpečná, místa se během dne mění, detekce zatím není možná. I lidé rozložení masomlejnem se [znovuzrodí](znovuzrozeni.md). Jen ničivá anomálie natrvalo zabije [Vlka](../mutants/vlk.md). Zdroj: [nebezpečné anomálie](../research/nebezpecne-anomalie.md)
