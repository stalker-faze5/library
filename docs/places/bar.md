# Bar

Oplocený pozemek, místo setkávání. Vede ho [Barman](../people/barman.md). V areálu Monolit obětoval [Hiršpina](../people/nuno-andejevic-hirspin.md). Jeden z triangulačních bodů signálu. Z telefonní sítě [Jasné Oblohy](../organizations/jasna-obloha.md) je nejdál (600 m).
