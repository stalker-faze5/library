# Koncern Ponce

- **Sídlo:** mrakodrap v [Barceloně](../places/barcelona.md)
- **Výskyt:** [Epilog 2](../web-articles/epilog-2.md)

Rodinný koncern s legálními i nelegálními příjmy (viz [Klaus Schreck](../people/klaus-schreck.md)). Jednací sál v horním patře: ocel, sklo, křišťálový lustr, staří mistři a Picasso. Stranu [Gregorije](../people/gregorij.md) nazývají "Protivník" (viz [Protivník](protivnik.md)).
