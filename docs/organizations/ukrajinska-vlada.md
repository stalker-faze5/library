# Ukrajinská vláda

- **Výskyt:** [Epilog 1](../web-articles/epilog-1.md), [Epilog 2](../web-articles/epilog-2.md)

Oficiálně vedla [operaci Exodus](../projects/operace-exodus.md) jako humanitární evakuaci desetitisíců civilistů po "přírodní katastrofě". [Protivník](protivnik.md) ji buď ovládá, nebo ji používá jako zástěrku.

Mediální verze podle [mladého muže s odznakem slunce](../people/mlady-muz-se-sluncem.md): vláda udělala maximum, ale evakuaci znemožnily teroristické organizace, místní ozbrojené skupiny a nebezpečné podmínky v Zóně.

[Koncern Ponce](koncern-ponce.md) chce proniknout do jejího dotačního systému (viz [plán koncernu Ponce](../projects/plan-koncernu-ponce.md)).
