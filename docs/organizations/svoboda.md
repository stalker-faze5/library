# Svoboda

Skupina stalkerů. Její polohu zmapoval [Hiršpin](../people/nuno-andejevic-hirspin.md) (33UWQ41456818, viz [CRC kartografie](../research/crc-kartografie.md)). Podle hráčské konverzace hlídala venku při výpravě do [objektu Lambda](../places/objekt-lambda.md). Možná souvisí se "Slobodou-armádou" z mapy Rozaliji Zorianič.
