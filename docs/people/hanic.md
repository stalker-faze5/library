# Dr. Hanič

- **Frakce:** neznámá, dříve projekt Duga a Tektonická energie
- **Výskyt:** STALKER 3.3

## Co víme

- 30. 4. 2004 napsal [Nosovovi](ivan-petrovic-nosov.md) varování před spuštěním Stroje. Píše z psychiatrické léčebny na Krymu, kam ho umístili kvůli jeho varováním.
- Opírá se o teorii noosféry (Vernadskij, Teilhard de Chardin). Věří, že kvantové pole Stroje destabilizuje psychickou energii noosféry. Pracovníci už mají halucinace, on sám vidí světelné úkazy a slyší hlasy.
- Pozdravuje sekretářku [Alexandru (Sašu)](sasa.md).
- V denících týmu je "osud Haniče" varováním. Zmiňuje se "jeho výzkum noosfér" a [projekt Duga](../projects/projekt-duga.md), který "skončil fiaskem".
