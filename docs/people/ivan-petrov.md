# Ing. Ivan Petrov

- **Frakce:** [Energoprom](../organizations/energoprom.md) (pravděpodobné)
- **Funkce:** vedoucí inženýr [projektu S.A.T.A.N.](../projects/projekt-satan.md)
- **Výskyt:** STALKER 3.3

Autor zprávy pro [Nosova](ivan-petrovic-nosov.md) z 30. 3. 2004 o čtyřech nehodách při stavbě Stroje (viz [nalezené dokumenty S.A.T.A.N.](../research/satan-nalezene-dokumenty.md)):

1. 12. 2. 2004: kvantová fluktuace při instalaci rezonátorů, 2 mrtví technici
2. 25. 2. 2004: tunelování energetických částic, výbuch, 2 mrtví a 3 těžce popálení
3. 8. 3. 2004: zamrznutí kvantových stavů při synchronizaci rotujících kruhů, 3 mrtví inženýři
4. 20. 3. 2004: dekoherence při kalibraci stabilizačních modulů, 2 mrtví a 3 zranění

Hlásí i halucinace u pracovníků: světelné úkazy a nesrozumitelné hlasy. Sám má noční můry, ve kterých Stroj vystupuje jako zlovolná entita. Někteří z týmu považují Stroj za "prokletý".
