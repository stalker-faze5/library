# PhDr. Ludwik Babinicz †

- **Frakce:** neznámá, spolupracoval s [Żelaznou Górou](../organizations/zelazna-gora.md)
- **Výskyt:** STALKER 3.3

Zesnulý. Našel v hospodské kronice archivní dokumenty (zpráva Wehrmachtu 1942, farářské dopisy 1696 až 1703). Na grantu [JUK: Náš kus Zóny II](../research/juk-nas-kus-zony.md) je uveden jako hlavní autor na jeho památku.
