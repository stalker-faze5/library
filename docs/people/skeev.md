# Skeev ("Skivo")

- **Frakce:** [Monolit](../organizations/monolit.md) (jisté)
- **Funkce:** velitel
- **Výskyt:** STALKER 3.3, zmínky z ročníků 3.1 a 3.2

Spolu s [Downiem](downie.md) tvoří dvojici "D&S". Hiršpinovi vysvětlili, proč Monolit sbírá duše (viz [Monolit: zápis Hiršpina](../research/monolit-hirspin.md)). Odběr vzorku Monolitu označili za svatokrádež. Po násilném odběru konfrontovali [Hiršpina](nuno-andejevic-hirspin.md) před [objektem Lambda](../places/objekt-lambda.md) s odjištěným granátem, ale nechali ho žít.
