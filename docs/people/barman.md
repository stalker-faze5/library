# Barman

- **Frakce:** nezávislý (odhad)
- **Výskyt:** STALKER 3.3

Majitel [Baru](../places/bar.md). Podle grantu [CRC](../organizations/crc.md) je "spolehlivá námezdní síla, zastávající logistickou část výzkumných operací", u něj se odevzdávají věci (například testovací oblek). Starousedlíci mu darovali knihu *Ohněm a mečem* se zatrženou pasáží o [Jurkovi Bohunovi](jurko-bohun.md). Zdroj pro [studii nováčků](../research/nuok-novacci.md).
