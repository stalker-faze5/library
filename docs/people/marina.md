# Marina

- **Frakce:** [Energoprom](../organizations/energoprom.md) (pravděpodobné, člen týmu S.A.T.A.N.)
- **Výskyt:** STALKER 3.3

Nejspíš autorka ženských záznamů v [denících z rámečků](../research/satan-deniky-z-ramecku.md). Chybí jí Moskva. Chce objevy zveřejnit, Ivan chce utajení. Vidí souvislost mezi experimenty a tektonickou aktivitou. [Lev](lev.md) je její tajný spojenec. Autor mužských záznamů se jí chce svěřit.
