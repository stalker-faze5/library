# Downie

- **Frakce:** [Monolit](../organizations/monolit.md) (jisté)
- **Výskyt:** STALKER 3.3, zmínky z ročníků 3.1 a 3.2

"Downie" je neherní jméno, herní není známé. Druhá polovina dvojice "D&S" se [Skeevem](skeev.md). Při monolitím raidu u [Baru](../places/bar.md) podřízl [Hiršpina](nuno-andejevic-hirspin.md) nožem. Během rozhovoru prý zvolal "ne!".
