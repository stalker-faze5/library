# CRC: Triangulace neznámého signálu (Belewski)

Zadání od ukrajinské rozvědky přes [CRC](../organizations/crc.md). Dva terénní týmy se SDR přijímači, směrovými anténami a LoRa trackery, centrální analýza v [komplexu Energoprom](../places/komplex-energoprom.md).

Signál má -100 dBm a je to analogová nosná s digitální telemetrií typu RS41 (meteorologická sonda), 435,3 MHz. Anomální je tím, že se nehýbe, nízko vysílá a nikdy nespadne. Poloha 49.36335, 15.57423, přístup zastavila radiace. Hypotéza: zařízení z utajeného vědecko-vojenského projektu pro monitoring nebo ovládání anomálií.

"Zóna si opět chrání svá tajemství, ale tentokrát jsme se dostali o krok blíž."
