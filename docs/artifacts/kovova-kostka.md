# Kovová kostka

- **Výskyt:** [Epilog 2](../web-articles/epilog-2.md)

Podivná kovová kostka ze [Zóny](../places/zona.md) na malém vozíku. Bzučí tichým, nepřirozeným tónem. Prodlužuje život [Leonovi Ponce](../people/leon-ponce.md). Vydrží zhruba 14 dní, pak je potřeba sehnat novou. Kostek tedy koncern získává víc a pravidelně.
