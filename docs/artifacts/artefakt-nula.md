# Artefakt Nula

- **Výskyt:** [Epilog 1](../web-articles/epilog-1.md), [Epilog 2](../web-articles/epilog-2.md), STALKER 3.3

## Z epilogů

Objevil ho [Protivník](../organizations/protivnik.md) díky výzkumu [Energopromu](../organizations/energoprom.md). Byl cílem [operace Exodus](../projects/operace-exodus.md). Místní vědci pochopili jeho princip (spolu s [monolitem](monolit.md)) rychleji, než Protivník čekal.

Po krachu operace kolem něj vznikla anomální struktura, která je podle [Dominique Kyle](../people/dominique-kyle.md) absolutně neprostupná. Artefakt je teď mimo dosah všech.

Byl součástí Stroje [projektu S.A.T.A.N.](../projects/projekt-satan.md). Jeho aktivace byla hlavní fáze spuštění projektu. Po několika dnech bouří vznikl [Objekt M-01, Monolit](monolit.md). Zdroj: [S.A.T.A.N.: fakta a hypotézy](../research/satan-fakta-a-hypotezy.md), [nalezené dokumenty](../research/satan-nalezene-dokumenty.md).
