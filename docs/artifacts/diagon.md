# Diagon

Čtyřboký hranol (198 x 198 x 216 mm) se zaoblenými hranami a kruhovými otvory ve všech stěnách, 417 g. Uvnitř je kulový prostor, v něm osm černých diagonálních vzpěr a uprostřed svítivě zelený průsvitný krystal. Plášť je černožlutý.

Plášť je anoda, krystal katoda. Stabilní napětí 4,127 V, po vhodném vybuzení možná násobně víc. Nalezen v lese mezi dlouhými svislými útvary [chmýří](../anomalies/chmyri.md).

Zdroj: [Hiršpinovy popisy artefaktů](../research/artefakty-hirspin-2004.md)
