# Dodekasonus

Nepravidelný dvanáctiboký hranol, 175 mm, 173 g, žlutý, stěny zrnitě černožluté. Při naklonění podél dvou os nepříjemně píská, dokud se nevrátí do vodorovné polohy. Na dotek bezpečný.

Nalezen v zadní kapse kalhot bezhlavé, dlouho tlející mrtvoly. Místo nálezu nešlo nafotit kvůli noci, mutantům a radiaci. Možná souvisí se [zvukovou anomálií](../anomalies/zvukova-anomalie.md) u bezhlavého těla.

Zdroj: [Hiršpinovy popisy artefaktů](../research/artefakty-hirspin-2004.md)
