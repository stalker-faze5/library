# Blokáda Zóny

- **Strana:** [Protivník](../organizations/protivnik.md)
- **Výskyt:** [Epilog 1](../web-articles/epilog-1.md), [Epilog 2](../web-articles/epilog-2.md)

Plán [mladého muže s odznakem slunce](../people/mlady-muz-se-sluncem.md): kolem [Zóny](../places/zona.md) postavit bezpečnostní bariéru, vstup jen přes vojenské kontrolní body. Každá bedna potravin, lékárnička a náboj projde jejich rukama. Oproti tomu má být Berlínská zeď "prolézačka". Oficiální důvod je zabránit, aby se "nekalé živly" rozšířily ven.

Cíl: vyhladovět [stalkery](../organizations/stalkeri.md). "Kdo bude kontrolovat zásobování, bude kontrolovat i Zónu."

[Dominique Kyle](../people/dominique-kyle.md) z [koncernu Ponce](../organizations/koncern-ponce.md) čeká, že se smyčka utáhne v nejbližších dnech a hranice zavře armáda i ostatní hráči. Koncern chce blokádu obejít pašeráckými trasami.
